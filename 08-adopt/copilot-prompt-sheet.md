# Microsoft Copilot prompt sheet for branch teams

Kamilisha answers procedure questions from the current circulars. Microsoft Copilot, where the bank licenses it, helps with the writing and summarising around that work. This sheet shows safe, useful prompts, and where each tool fits.

## Which tool when

| Need | Use | Why |
| --- | --- | --- |
| "What is the current procedure for...?" | Kamilisha | Answers only from Live circulars, with the version and section cited |
| Summarise or explain a document you have open | Copilot | Works on the document in front of you |
| Draft a message, notice or training material | Copilot | Writing help; you check and send |
| Anything with customer personal data | Neither | Bank rule: customer data stays in the bank's systems |

## Prompts that work

**Branch manager: morning huddle note**
> Draft a 5-line huddle note for branch staff about this change: [paste the "What changed" box from the circular]. Plain English, then the same in Swahili. End with where to find the full circular.

**Supervisor: explain a change to the team**
> Using only the circular I have open, list what changed in this version compared with the old one, in 5 bullet points a new teller would understand.

**Training unit: quiz from a circular**
> From the circular I have open, write 5 multiple-choice questions on its mandatory control steps, with the correct answer and the section number for each.

**Training unit: plan from the question log**
> Here are this week's most-asked questions by procedure: [paste the counts from the Kamilisha question log; no names]. Suggest three 15-minute refresher topics and which branches should get each.

**Relationship officer: customer documents list**
> Turn this documents list into a short, polite checklist I can give a sole proprietor opening an account, in English and Swahili: [paste the list from Kamilisha's answer]. Do not add documents.

**Procedure owner: plain summary for a new circular**
> Write a 4-line plain-language summary of this circular for branch staff, and a one-line "what changed" box. Do not change any requirement.

## Rules for every prompt

1. **No customer data.** Never paste names, account, card, phone or ID numbers.
2. **Check before you use.** Copilot can make mistakes. Check every requirement against the circular.
3. **Procedures come from Kamilisha or the circular,** not from Copilot's general knowledge, which may be out of date.
4. **Say what not to change.** Add "Do not add or change any requirement" when Copilot rewrites procedure text.
5. **You send it, you own it.** Copilot drafts; you review and decide.
