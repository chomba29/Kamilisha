# User journeys

Three fictional staff members, today and with Kamilisha.

## 1. Neema, customer service officer: card replacement

| Today | With Kamilisha |
| --- | --- |
| Customer reports a lost card; queue is long | Same |
| Searches the intranet, opens a 30-page circular, gives up | Types "customer lost card" |
| Asks a colleague, who says "just block it on the system" (old rule) | Gets 6 numbered steps; the signed blocking form is marked CONTROL and "changed on 1 Sep 2026" |
| Blocks the card without the form | Takes the signed form, then blocks the card |
| QA returns the file; customer is called back | File passes QA first time |
